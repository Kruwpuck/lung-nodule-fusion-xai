# Research Methodology Guidance: Cross-Granularity Comparison, Fusion Diagnosis, and Stability Reporting for LIDC-IDRI Lung Nodule Malignancy Classification

## TL;DR
- To compare across your four label arms fairly, do NOT compare binary AUC vs 3-/4-class macro-AUC directly; instead collapse every arm's predictions to a common benign-vs-malignant probability, evaluate all arms on the SAME fixed 1,391-nodule binary-eligible test subset per fold, and test differences with the paired DeLong test. This is the only defensible "does the number of classes matter?" experiment.
- Your fusion result (radiomics-only 0.9313 > all fusion variants) is a real, literature-consistent finding, not a bug: on small lung-nodule cohorts radiomics routinely rivals or beats CNNs, and fusing a strong modality with a weak one (your cnn_only 0.7853) is documented to degrade performance. Fix the known 96px→64px resolution bug first, then test gated/attention fusion and per-branch normalization — but "radiomics beats fusion" is itself publishable.
- VGG16 being most stable (CV 0.0400) vs EfficientNet-B0 (0.0865) should be tested with Levene's/Brown-Forsythe test on variance (not just CV); the SGD gap (up to 0.1457 AUC) is a learning-rate mismatch (SGD fine-tuning needs ~10–100× Adam's LR), correctly framed as an experimental limitation, not an optimizer property.

## Key Findings

1. **Comparability across granularities requires a common evaluation basis.** Binary AUC, one-vs-rest macro-AUC, and ordinal QWK/MAE are on different scales and computed on different sample counts (1,391 vs 2,138 vs 4,276), so they cannot be directly compared. The correct approach is to reduce every arm to the same binary benign-vs-malignant decision on the same samples.
2. **Adding an "indeterminate" class and adding easy negatives affect metrics in opposite, known directions.** Easy negatives inflate ROC-AUC through abundant true negatives; the anti-inflation rule (headline = benign-vs-malignant AUC on the nodule subset) is the right control.
3. **Ordinal framing of LIDC malignancy tends to improve accuracy modestly over nominal/binary on the SAME data, mainly by exploiting the discarded "indeterminate" nodules** — but reported gains are in accuracy, and most papers do not report QWK/MAE despite the ordinal claim.
4. **Radiomics beating CNN/fusion at ~1,400 nodules is consistent with the literature.** Multiple LIDC studies report radiomics AUC in the 0.79–0.94 range, often matching or exceeding CNNs when data is limited.
5. **The correct statistical test for "model X is more stable than model Y" is a test on variances (Levene/Brown-Forsythe/Fligner-Killeen), not a comparison of CV point estimates.** For ranking models across many configurations, use Friedman + Nemenyi.
6. **The SGD deficit is a learning-rate artifact.** Standard SGD fine-tuning LR is ~1e-2 to 1e-1, roughly 10–100× the Adam LR you used; at 1e-4 SGD under-converges in 50 epochs.
7. **XAI figures should use identical samples across models, fixed colorbar normalization, ground-truth mask overlays, and include failure cases.**
8. **Splitting into two papers (Track 1 fusion/XAI; Track 2 model-comparison/stability) is legitimate partitioning, not salami slicing, provided each is a distinct scientific question with transparent cross-citation.**

## Details

### 1. Cross-granularity comparison methodology (highest priority)

**The core problem.** You have four arms trained on overlapping data but scored with metrics that live on different scales and different denominators. A 4-class macro-AUC of 0.90 and a binary AUC of 0.90 are not the same quantity; multi-class AUC summaries are known to be inadequate for model selection because the same average can correspond to very different classifiers (Kim et al., "Overlooked pitfalls in multi-class machine learning classification in radiation oncology and how to avoid them," *Physica Medica*). A raw metric-to-metric comparison therefore cannot answer "does the number of classes affect performance?"

**What IS comparable — collapse everything to a common binary decision.** The standard, defensible move is one-vs-rest / collapse-to-binary: reduce each multi-class output to a benign-vs-malignant score and evaluate with ordinary binary AUC. This is the widely documented OvR reduction (scikit-learn "Multiclass Receiver Operating Characteristic (ROC)" documentation). Concretely:
- **Arm A (binary):** use the malignant-class probability directly.
- **Arm C (3-class benign/malignant/indeterminate):** collapse to benign-vs-malignant by renormalizing the two relevant class probabilities — P(malignant)/(P(benign)+P(malignant)). Probability-renormalization collapse is preferred over argmax collapse because it preserves the continuous score AUC needs; argmax collapse discards ranking information and yields only a confusion-matrix point.
- **Arm B (ordinal 1–5):** map to P(malignant) via the cumulative probability P(rating > 3), or via expected-rating thresholding.
- **Arm D (4-class with no-nodule):** restrict to the nodule subset and collapse exactly as Arm C — precisely your stated anti-inflation rule.

**The common fixed test subset is the right control.** Evaluate every arm on the SAME 1,391 binary-eligible nodules, per fold, using the frozen seed-42 split. This holds the denominator constant so that any AUC difference is attributable to the label granularity used in *training*, not to which samples were scored. This is the cleanest implementation: train under each arm's label scheme, then score all arms on the identical held-out binary-eligible cases. Report per-fold binary AUC (mean ± SD across the 5 folds) for each arm.

**Why the common subset matters — the easy-negative inflation problem.** ROC-AUC is formally independent of class balance, but in practice adding large numbers of easy true negatives inflates apparent performance: expanding the negative pool "adds lots of easy true negatives … which inflate AUC scores." Your Arm D doubles the sample with 2,138 no-nodule hard negatives; a raw 4-class or benign-vs-all AUC would look better without the model being better at the clinically relevant benign-vs-malignant distinction. Restricting the headline metric to the nodule subset (as you already specify) is exactly the recommended defense. Note also that ROC-AUC is comparatively robust to imbalance whereas PR-AUC is highly sensitive to prevalence (Movahedi et al., "The receiver operating characteristic curve accurately assesses imbalanced datasets," PMC11240176; Brabec et al., "On Model Evaluation under Non-constant Class Imbalance," which shows PR-AUC and F1 depend on the imbalance rate and even the *ordering* of classifiers under PR-AUC changes with imbalance). Because your arms have different prevalence, report AUC as primary but show PR-AUC / sensitivity–specificity at a fixed operating point as secondary, and never compare PR-AUC across arms with different prevalence.

**Does adding an "indeterminate" class help or hurt binary discrimination?** The LIDC ordinal-regression literature indicates that *using* the indeterminate/unsure nodules during training (rather than discarding them) tends to improve the benign-vs-malignant decision. In CLIP-Lung (Lei et al., MICCAI 2023, DOI 10.1007/978-3-031-43990-2_38), the LIDC-B setting (3-class in training, binary at test) and the binary-only LIDC-C setting are directly compared in the paper's Table 2, and models trained with the extra "unsure" class remain competitive with binary-only training (the paper reports labeling accuracy up to 89.1% and AUC ≈ 0.91 under full supervision). This suggests the extra class acts as a regularizer / auxiliary signal rather than hurting binary discrimination — but the effect is modest and model-dependent. Report this directly: it is a genuinely interesting sub-finding.

**Statistical testing across arms with different n.** DeLong's test requires the two AUCs to be computed on the SAME cases (it exploits within-subject covariance to gain power; "when the same patients contribute to both ROC curves, the two AUC estimates move together," so the difference is estimated more precisely than from independent samples — DeLong, DeLong & Clarke-Pearson, *Biometrics* 1988). Therefore:
- On the common 1,391-nodule subset, all arms ARE evaluated on the same cases → use the **paired (correlated) DeLong test** for every pairwise arm comparison, exactly as you already do for the 21 fusion pairs.
- You cannot DeLong-compare a metric computed on 2,138 samples against one on 1,391 samples (an unpaired DeLong exists but throws away the pairing and is needlessly conservative and inappropriate here). The common-subset design dissolves the problem.
- Because you have 5 folds and 4 arms, a cleaner omnibus alternative is to treat per-fold binary AUC as the unit and run a Friedman test across arms with Nemenyi post-hoc (Demšar, "Statistical Comparisons of Classifiers over Multiple Data Sets," *JMLR* 7:1–30, 2006) — this ranks arms within each fold and sidesteps the same-cases requirement.

### 2. Ordinal vs nominal framing

The LIDC ordinal literature is substantial and IEEE-citable:
- **Liao, Liang, Li, Hu, Song, "Evaluate the Malignancy of Pulmonary Nodules Using the 3-D Deep Leaky Noisy-OR Network," IEEE Transactions on Neural Networks and Learning Systems 30(11):3484–3495, 2019, DOI 10.1109/TNNLS.2019.2892409** — the Data Science Bowl 2017 winner; models malignancy via a probabilistic leaky noisy-OR combination.
- **Lei, Zhu, Zhang, Shan, "Meta Ordinal Regression Forest for Medical Image Classification With Ordinal Labels," IEEE/CAA Journal of Automatica Sinica 9(7):1233–1247, 2022, DOI 10.1109/JAS.2022.105668** (arXiv:2203.07725) — MORF on LIDC 3-class ordinal (benign ≤2.5, unsure 2.5–3.5, malignant ≥3.5). In the conference version, MORF (ResNet-18 accuracy ≈ 0.573) beats cross-entropy (0.542) and ordinal baselines (Poisson 0.527, NSB 0.534, UDM 0.546, DORF 0.568). Ordinal framing beat nominal CE in all reported settings.
- **Lei, Li, Shen, Zhang, Shan, "CLIP-Lung: Textual Knowledge-Guided Lung Nodule Malignancy Prediction," MICCAI 2023, LNCS 14226:403–412, DOI 10.1007/978-3-031-43990-2_38** (arXiv:2304.08013) — constructs LIDC-A (3-class train+test, best acc 60.9±0.4%), LIDC-B (3-class train, binary test, best acc 87.5±0.5%), LIDC-C (binary train+test, best acc 89.5±0.4%); CLIP-Lung beats CLIP, CoCoOp, and ordinal baselines (Poisson/NSB/UDM/CORF) on all three.
- **Liao, Xie, Hu, Xia, "Learning From Ambiguous Labels for Lung Nodule Malignancy Prediction," IEEE Transactions on Medical Imaging 41(7):1874–1884, 2022, DOI 10.1109/TMI.2022.3149344** (arXiv:2104.11436) — treats malignancy as 5-class (score 1–5); multi-view divide-and-rule (MV-DAR) outperforms reliable-only and average-annotation (AVE) baselines.
- **Zhu, Shan, Zhang, Che, Xu, Zhang, Shi, Wang, "Convolutional Ordinal Regression Forest for Image Ordinal Estimation," IEEE Transactions on Neural Networks and Learning Systems 33(8):4084–4095, 2022, DOI 10.1109/TNNLS.2021.3055816** — the CORF method (validated on facial-age/aesthetics in the original; used as a LIDC baseline by MORF/CLIP-Lung).

**Conclusion on ordinal vs binary.** Ordinal framing generally gives modest accuracy gains over nominal treatment of the same 3-class problem, primarily by respecting the benign→malignant ordering and by absorbing the "unsure" nodules as training signal. However, a striking gap in this literature is that these papers report **accuracy (and sometimes per-class F1/recall) but almost never QWK, MAE, or macro-AUC**, despite the ordinal claim. This is a legitimate criticism you can make and a differentiator for your work: if you report quadratic-weighted kappa (QWK) and MAE for Arm B alongside collapsed-binary AUC, you would be reporting the ordinal-appropriate metrics that most LIDC ordinal papers omit. QWK is the standard ordinal agreement metric (quadratic weights wᵣₛ = 1 − (r−s)²/(C−1)²; Warrens and the weighted-kappa literature) and is the right companion to MAE and one-off/adjacent accuracy for a 1–5 scale. **Fair comparison requires you to also collapse the ordinal model to binary** and compare on the common subset, because QWK/MAE are simply not defined for the binary arm.

### 3. Why radiomics-CNN fusion fails, and legitimate fixes (second priority)

**First, fix the known bug.** Your `stage_03b_fusion.py` evaluates 96px-trained checkpoints at 64px, invalidating the cnn_only column (DenseNet201 0.6432 in-ablation vs 0.8988 standalone). A train/test resolution mismatch is a classic silent performance killer and must be corrected before any scientific claim about fusion is made; otherwise the fusion branches inherit a crippled CNN embedding. Re-run the ablation at matched resolution.

**Second, understand why fusion legitimately loses even after the fix.**

- **Small-sample regime.** At ~1,391 nodules, hand-crafted radiomics with feature selection is highly competitive with or superior to CNNs. Astaraki, Yang, Zakko, Toma-Dasu, Smedby, Wang ("A Comparative Study of Radiomics and Deep-Learning Based Methods for Pulmonary Nodule Malignancy Prediction in Low Dose CT Images," *Frontiers in Oncology* 11:737368, 2021, DOI 10.3389/fonc.2021.737368; PMID 34976794 / PMC8718670; 1,297 nodules, 5-fold CV) report, verbatim, optimized "radiomics, end-to-end deep learning, and deep-feature based models achieved AUROC values of 0.921 ± 0.010, 0.824 ± 0.021, and 0.936 ± 0.011 … best prediction accuracy from the hybrid feature set (AUROC: 0.938 ± 0.010)" (their untuned baselines were 0.792 ± 0.025 / 0.801 ± 0.018 / 0.817 ± 0.032). Your radiomics 0.9313 and CNN 0.7853–0.8988 sit squarely in this range. The systematic review by Demircioğlu ("Are deep models in radiomics performing better than generic models? A systematic review," *European Radiology Experimental* 7:11, 2023, DOI 10.1186/s41747-023-00325-0; 69 studies) found that on internal validation deep models beat generic/handcrafted models in 74% (49/66) but generic models won in 20% (13/66) with no difference in 6%, at a median AUC difference of 0.045; fused models outperformed both in 72% (20/28) but the median gain was only about +0.02 AUC internally (+0.025 on external validation). So radiomics ≈ or > fusion at your scale is expected, and even when fusion "wins" the typical margin is tiny.
- **Fusing a weak modality with a strong one degrades performance.** This is now well documented. "Integrating a poor-performing modality with other higher-performing modalities degrades predictive accuracy" (Bhattacharya et al., "Synergy vs. Noise: Performance-Guided Multimodal Fusion for Biochemical Recurrence-Free Survival in Prostate Cancer," arXiv:2511.11452). The underlying mechanism is "greedy learning" / "modality competition": Wu, Jastrzebski, Cho & Geras ("Characterizing and overcoming the greedy nature of learning in multi-modal deep neural networks," ICML 2022, PMLR 162:24043–24055; arXiv:2202.05306) show that although multimodal learning is provably superior in principle, in practice "the best-performing unimodal networks often outperform jointly trained multimodal networks" because joint training greedily optimizes the dominant modality. Your cnn_only 0.7853 is exactly the weak modality that theory predicts will drag fusion toward itself.
- **Feature-scale and dimensionality imbalance.** A 256-dim CNN embedding concatenated with a ~20-dim standardized radiomic vector creates magnitude and dimensionality imbalance so that one branch dominates or is ignored. Standard fixes: L2-normalize / standardize each branch to comparable scale before concatenation; project the CNN embedding down (e.g., 256→32) so the branches are dimensionally balanced; or up-weight the radiomic branch.

**Legitimate architectural improvements to TEST (with precedent):**
- **Gated Multimodal Units (GMU)** — Arevalo, Solorio, Montes-y-Gómez, González, "Gated Multimodal Units for Information Fusion," ICLR 2017 workshop, arXiv:1702.01992. Multiplicative gates learn how much each modality influences the fused representation; outperformed concatenation and mixture-of-experts on MM-IMDb (weighted F-score 0.617). Directly applicable: a gate can learn to down-weight the weak CNN branch.
- **Tensor Fusion Network (TFN)** — Zadeh, Chen, Poria, Cambria, Morency, "Tensor Fusion Network for Multimodal Sentiment Analysis," EMNLP 2017, DOI 10.18653/v1/D17-1115. Outer-product fusion models inter-modality interactions; expressive but parameter-heavy (a risk on small data).
- **Cross-attention / co-attention fusion** and **learned / confidence-based modality weighting** (surveyed in Baltrušaitis, Ahuja, Morency, "Multimodal Machine Learning: A Survey and Taxonomy," IEEE Transactions on Pattern Analysis and Machine Intelligence 41(2):423–443, 2019, DOI 10.1109/TPAMI.2018.2798607).
- **Regularization for small-data fusion:** modality dropout, auxiliary per-branch losses / deep supervision, and gradient-modulation schemes (Peng et al., OGM-GE, "Balanced Multimodal Learning via On-the-fly Gradient Modulation," CVPR 2022) that rebalance the learning speed of strong vs weak modalities.

**Frozen vs fine-tuned / two-stage vs joint.** The systematic review of imaging+EHR fusion (Huang et al., "Fusion of medical imaging and electronic health records using deep learning: a systematic review and implementation guidelines," *npj Digital Medicine*, PMC7567861) notes joint (end-to-end) fusion "is implemented using neural networks which can be a limitation especially with smaller datasets better suited for traditional machine learning models," and that early fusion is a reasonable first strategy. Practical recommendation: test (a) two-stage with a frozen, correctly-resolution-matched backbone feeding an XGBoost/late fusion, and (b) end-to-end joint training with per-branch losses; report both.

**The correct scientific stance when fusion genuinely loses.** "Radiomics beats fusion" is a legitimate, publishable finding. The medical-imaging-ML methodology literature explicitly calls for publishing negative results to counter the file-drawer problem (Varoquaux & Cheplygina, "Machine learning for medical imaging: methodological failures and recommendations for the future," *npj Digital Medicine* 5:48, 2022, DOI 10.1038/s41746-022-00592-4, which documents that in a sample of ML papers 97% of significance-testing papers reported p<0.05 — an implausible rate reflecting publication bias). Published fusion papers that report where fusion does NOT help (the ~+0.02 median gain and the 20% "generic wins" rate in Demircioğlu 2023; the prostate "Synergy vs. Noise" paper) demonstrate the norm. Your DeLong evidence — radiomics best on all 21 pairs, 13/21 fusion significantly worse (p<0.05), 8 not significantly different, 0 wins — is a strong, honest result. Frame the architectural experiments as hypothesis tests ("does gated fusion recover the loss caused by modality imbalance?"), not as a search for a configuration that finally wins.

### 4. LIDC-IDRI radiomics-vs-DL precedent

Representative reported AUCs on LIDC/LDCT lung-nodule malignancy:
- Astaraki et al. 2021 (1,297 nodules): radiomics 0.921, end-to-end DL 0.824, deep-feature radiomics 0.936, hybrid 0.938 (untuned baselines 0.792 / 0.801 / 0.817).
- The "Efficient pulmonary nodules classification using radiomics and different artificial intelligence strategies" study (PMC10195968) reports ROC 0.943–0.960 for radiomics-based strategies on 1,297 LIDC nodules, "much better than reported by transfer learning approaches."
- NoduleX (Causey et al., *Scientific Reports*) reports CNN+quantitative-image-feature (QIF) fusion AUC ≈ 0.97.
- GGN-focused fusion studies (Xia et al., *Frontiers in Oncology* 2020, DOI 10.3389/fonc.2020.00418) report DL 0.83 ± 0.05, radiomics 0.87 ± 0.04, fusion 0.90 ± 0.03 (p<0.05) — but on a *different* (invasiveness) task and a small cohort.

**Verdict:** Your radiomics AUC 0.9313 is entirely consistent with the LIDC literature (0.79–0.96 depending on optimization), and your CNN 0.7853–0.8988 is in the normal transfer-learning range for 2.5D patches. That radiomics wins at your scale is a mainstream, well-supported outcome — not an anomaly to be explained away.

### 5. Hyperparameter stability reporting

**CV is a reasonable descriptive stability metric but is not a test.** Reporting mean AUC, SD, 95% CI, and CV across the sweep is standard descriptive practice. To formally claim "VGG16 is MORE stable than EfficientNet-B0," you must test equality of *variances*, not means:
- **Levene's test** (mean-based) and **Brown-Forsythe test** (median-based, the Levene family, more robust to non-normality) test H0: equal variances across groups. Brown-Forsythe is generally preferred for AUC distributions that may be skewed.
- **Fligner-Killeen test** is the most robust to non-normality and is a good confirmatory choice.
- Because you compare variance across several backbones, run the omnibus variance test then pairwise with multiple-comparison correction (e.g., Holm).

**For ranking models across the 180-run sweep:** use the **Friedman test + Nemenyi post-hoc with a critical-difference diagram** (Demšar, *JMLR* 2006), treating each (optimizer × weight-decay × fold) configuration as a block and ranking backbones within it. This is the field-standard method for "model X ranks significantly above model Y across many configurations" and is non-parametric — appropriate here since the number of blocks per cell is small and normality is not assured.

**ANOVA decomposition of variance sources.** To show the optimizer effect (Adam−SGD up to 0.1457 AUC) dwarfs the weight-decay effect (max 0.0218), a factorial ANOVA (or its non-parametric analog) with factors {backbone, optimizer, weight-decay, fold} and reporting η²/variance-component per factor is the clean way to quantify "optimizer effect ≈ 7× weight-decay effect." Report effect sizes, not just p-values. Report the CV descriptively, but base the stability *claim* on Brown-Forsythe/Levene (for variance) and the granularity/model-ranking claim on Friedman/Nemenyi.

### 6. SGD under-convergence

Your suspicion is correct and defensible as an experimental limitation. The standard SGD fine-tuning learning rate is roughly 1e-2 to 1e-1 — about 10–100× higher than a typical Adam/AdamW LR. Kumar et al. ("How to Fine-Tune Vision Models with SGD," arXiv:2211.09359) sweep SGD over [3e-5, 1e-4, 3e-4, 1e-3, 3e-3, 1e-2] but AdamW over [3e-7, 1e-6, 3e-6, 1e-5, 3e-5, 1e-4], noting "as standard, we use smaller learning rates for AdamW"; the canonical ImageNet SGD recipe uses "SGD with a momentum of 0.9, weight decay of 1e-4 and initial learning rate of 0.1" (Rosenfeld et al., "A Constructive Prediction of the Generalization Error Across Scales," arXiv:1909.12673; corroborated by PaddleClas training tricks). At LR 1e-4 for only 50 epochs, SGD with momentum 0.9 will under-converge relative to Adam/AdamW, which adapt per-parameter step sizes and effectively take larger early steps.

Crucially, the literature shows SGD is *competitive with or better than* Adam when its LR is properly tuned: Kumar et al. report "SGD (freeze-embed) … are competitive with or better than AdamW," with SGD (freeze-embed) achieving the best out-of-distribution accuracy (76.7% vs 76.0% for AdamW); and Keskar & Socher ("Improving Generalization Performance by Switching from Adam to SGD," arXiv:1712.07628) close the Adam–SGD generalization gap on most tasks. Therefore the 0.09–0.15 AUC deficit reflects a **learning-rate mismatch, not an inherent optimizer inferiority** — state this explicitly and note that a fair SGD comparison would require an SGD-specific LR sweep (e.g., {1e-3, 1e-2, 1e-1}). That Adam and AdamW are nearly identical (<0.0051 apart) is also expected, since AdamW only changes weight-decay handling.

### 7. XAI figure conventions for per-model comparison

Best practices drawn from exemplary medical-imaging XAI figures:
- **Use identical samples across all models** for a controlled visual comparison — the same nodules down every column, models across rows (as in the transformer-interpretability medical-imaging comparison, arXiv:2503.09535, and MedIM, *Medical Image Analysis*, DOI 10.1016/j.media.2024.103264).
- **Overlay ground-truth lesion masks/boxes** (red boxes/contours for radiologist annotation) so readers can judge localization against truth; standard in VinDrCXR and BraTS Grad-CAM figures.
- **Quantify with the pointing game** (max-activation-in-mask hit rate), which you already do — report it alongside the qualitative panels, as in the skin-lesion pointing-game example (98.27% hit rate, arXiv:2606.18707).
- **Fixed colorbar normalization** across all panels (same min–max, upsample-then-overlay, consistent colormap and alpha blending) so heat intensities are comparable between models; include the colorbar.
- **Show failure cases**, not only successes — include at least one row where the high-pointing models (DenseNet121 / ConvNeXt-Tiny, 0.7167) and low-pointing models (ResNet50 0.1167, EfficientNet-B0 0.0833, and the 0.0000 group MobileNetV3-small/ViT-Base/GoogLeNet) diverge, and discuss that low pointing accuracy does not necessarily mean low classification AUC (a documented XAI caveat — Grad-CAM localization can be poor even for accurate classifiers, and Grad-CAM is known to be inadequate for ViTs specifically).
- Note the resolution caveat: Layer-CAM at an ~8×8 stage is intrinsically coarse (a known limitation set by the spatial size of the chosen convolutional stage); state the upsampling method.

### 8. Splitting one study into two papers

Your split — **Track 1** (radiomics-CNN fusion + XAI, the negative fusion result) and **Track 2** (backbone comparison + hyperparameter stability + cross-granularity) — is legitimate partitioning, not salami slicing, because they answer **distinct scientific questions**. COPE's operational definition is the test: salami slicing divides work that covers "the same population, methods, and question" (COPE, "Handling duplicated or redundant content (salami slicing)"). Your two tracks share the population and preprocessing but pose different questions (fusion efficacy/explainability vs optimizer/architecture stability and label granularity), so they fall on the acceptable side of the continuum.

Requirements to stay clearly legitimate (COPE; ICMJE Recommendations for the Conduct, Reporting, Editing and Publication of Scholarly Work in Medical Journals; IEEE publication policy):
- **Each report must independently and fully state** the dataset (LIDC-IDRI; Armato et al., *Medical Physics* 38(2):915–931, 2011, DOI 10.1118/1.3528204), the frozen seed-42 patient-level 5-fold split, the 2.5D patch preprocessing, and label definitions. Duplicated methods text is the most acceptable form of overlap ("duplicated text in the methods might be more acceptable than duplicated text in the discussion" — COPE).
- **Cross-cite explicitly and transparently.** Each paper must cite the other (or the shared preprint/thesis) so an editor can see the complete dataset; ICMJE requires authors to alert editors to related submissions based on the same dataset.
- **Do not double-count shared results.** The shared split and preprocessing can be cross-referenced; do not present the same table/figure of the same result as novel in both.
- **State the reason for the split** (two distinct methodological contributions) in a cover letter, as COPE/ICMJE expect.
- **The line:** if a reader seeing both side by side would conclude "these are clearly different scientific questions with transparent overlap," it is legitimate; if they would conclude "this is one study cut to inflate count," it is salami. Reporting the same endpoint (binary malignancy AUC) as the primary novelty in both would cross that line — so keep the fusion/XAI endpoints in Track 1 and the stability/granularity endpoints in Track 2.

## Recommendations

**Stage 1 — Fix and re-baseline (before any new claims).**
1. Fix the `stage_03b_fusion.py` input_size bug; re-run the ablation at matched 96px resolution. Benchmark: cnn_only for DenseNet201 should recover toward ~0.8988. Until this passes, make no fusion claim.
2. Implement the common-subset evaluation: retrain each arm under its label scheme, then score ALL arms on the identical 1,391-nodule binary-eligible held-out set per fold via probability-renormalization collapse to benign-vs-malignant. This becomes the single comparable table.

**Stage 2 — Cross-granularity analysis (Track 2 headline).**
3. Report per-fold collapsed-binary AUC (mean ± SD) for Arms A/B/C/D, plus Arm B's QWK/MAE/one-off accuracy as ordinal-native metrics.
4. Test arm differences with paired DeLong on the common subset AND Friedman+Nemenyi across folds. Decision rule: claim "granularity affects performance" only if DeLong p<0.05 survives on the common subset; if not significant, report the null result honestly.

**Stage 3 — Fusion improvement experiments (Track 1).**
5. Test, in order of expected payoff: (a) per-branch normalization + CNN-embedding down-projection to ~32-dim; (b) Gated Multimodal Unit fusion (Arevalo et al. 2017); (c) modality dropout + auxiliary per-branch losses; optionally (d) gradient modulation (OGM-GE). Benchmark to change the conclusion: a fusion variant must beat radiomics-only (0.9313) with DeLong p<0.05 on ≥1 backbone. If none does after these principled fixes, publish "radiomics beats fusion" as the finding.

**Stage 4 — Stability and optimizer reporting (Track 2).**
6. Replace CV-only claims with Brown-Forsythe/Levene tests on AUC variance across backbones (stability claim) and a factorial ANOVA reporting variance components for optimizer vs weight-decay (to substantiate the ~7× ratio).
7. Add an SGD-specific LR sweep {1e-3, 1e-2, 1e-1}; if the gap closes, report SGD's deficit as a learning-rate/limitation artifact. If you cannot re-run, state the limitation explicitly with the citations above.

**Stage 5 — Figures and ethics.**
8. Rebuild XAI panels with identical samples across models, fixed colorbar, GT-mask overlays, and a failure-case row.
9. Ensure both papers fully restate dataset/split/preprocessing and cross-cite; put the split rationale in each cover letter.

**Thresholds that change the recommendations:** if the resolution-fixed cnn_only rises above ~0.90 and a gated-fusion variant then beats radiomics with DeLong p<0.05, the headline flips from "radiomics beats fusion" to "properly-balanced fusion wins." If Brown-Forsythe shows no significant variance difference between VGG16 and EfficientNet-B0, drop the "most stable" claim and report only descriptive CV.
